## Proyectos destacados

### Administrativo
**Una necesidad del trabajo convertida en una aplicación.**

Aplicación web en desarrollo que nació de una necesidad real
en mi entorno laboral: organizar información de clientes,
planificar visitas y llevar registro del trabajo realizado.

Incluye:

- Gestión de clientes, zonas y mapas.
- Planillas de trabajo y asignación a técnicos.
- Registro de resultados e históricos.
- Separación de funciones entre dueño y cuentas técnicas.
- Seguimiento de pagos y dashboard de cobranzas.
- Pruebas con JUnit y una demo Docker con datos ficticios.

**Tecnologías:** Java · Spring Boot · PostgreSQL · Docker ·
HTML · CSS · JavaScript

**Estado:** en desarrollo y mejora continua.

### Tabletop Utilities
**De una idea personal a una aplicación para Android.**

Aplicación desarrollada con Unity que reúne herramientas
para acompañar partidas de juegos de mesa:

- Tiradas de dados.
- Contadores de vida para dos o cuatro equipos.
- Lanzamiento de moneda.
- Creación aleatoria de grupos.

Un proyecto con el que llevé una idea hasta una versión
instalable en Android y trabajé en la interacción y
organización de sus funcionalidades.

**Tecnologías:** Unity · C# · Android

**Estado:** versión Android generada en formato APK.
Presentación y distribución pública en preparación.
